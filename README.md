# web_Veterinaria

## Usuarios de prueba

El formulario de [login.html](login.html) incluye estas cuentas para la demo estática:

| Usuario | Contraseña | Rol |
| --- | --- | --- |
| `admin` | `admin123` | Administrador |
| `cliente` | `cliente123` | Cliente |

Después de iniciar sesión, `admin` redirige a `admin.html` y `cliente` a `cliente.html`.
Este login funciona en el navegador y no reemplaza una autenticación segura de backend para producción.
